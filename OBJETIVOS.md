# Objetivos

> Nota: estos objetivos no son para resolver ahora ni para recordarlos a cada rato. Son solo de referencia, por si se consultan.

- Algún sistema para crear cuentas. Tal vez registrándose con el correo de la empresa.
- Diseñar versión móvil de la app.
- Conectar con Supabase. Pagar un plan para mayor capacidad de almacenamiento.
- Versión móvil para Android y para iPhone, sobre todo para iPhone.
- App offline: poder acceder a la app y escribir tareas sin acceso a internet.
- Resolver cuando 2 usuarios editan las mismas tareas.
- Automatizaciones con IA: correos electrónicos, entrevistas → generar tareas automáticamente.
